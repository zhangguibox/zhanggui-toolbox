9. **参赛作品名称**：**掌柜工具箱——小生意一站式经营助手**
10. **您本次选择参赛的赛道**：**商业增长**（产品的核心价值是帮小生意获客、管账、提效）
11. **请用一句话介绍你的作品**：
    > 掌柜工具箱把个体户和小店老板最常干的四件杂事——报价、对账、排期、记账——装进一个免费网页工具里，手机电脑打开即用，数据只留在自己设备上。
12. **请尽量详细地介绍您的作品**：
    > 掌柜工具箱是一款面向个体户、微商和自由职业者的纯前端 Web 应用，包含四个模块：
    > 1. **报价单生成器**：填写店方/客户信息与项目明细，实时预览排版专业的报价单，一键导出高清图片直接发微信，或打印为 PDF；支持税率、优惠金额、人民币大写金额，常用报价可存为模板重复使用。相比 Word/Excel 手工排版，出单时间从半小时缩短到 1 分钟。
    > 2. **账单对账助手**：粘贴或上传微信/支付宝导出的账单 CSV，自动解析交易记录，并按关键词智能归类（平台结算、进货采购、房租水电等）；自动生成月度收支趋势图与支出分类占比图，支持逐笔调整分类、导出汇总表。相比手工拉表，对账从半天缩短到几分钟，而且账单内容只在本机解析，隐私安全。
    > 3. **需求排期**：把客户零散的需求整理成任务清单，按优先级和预计天数自动排出一张工期表（可跳过周末），一键导出图片或复制文字发给客户和同事，谁该干什么、哪天交付一目了然。
    > 4. **收支账本**：随手记账，按月统计收入/支出/结余，分类占比一目了然，支持 JSON 备份与导入，数据不怕丢。
    > 亮点：无需注册登录、无服务器成本、支持 PWA 安装与离线使用、所有数据本地存储。产品用 AI 编程工具（TRAE）辅助开发完成，从需求到上线只用了不到两周。
