# TRAE SessionID 获取指南（问卷第 20–21 题）

大赛问卷要求填写「TRAE 在作品开发过程中的关键 SessionID」（方案设计 / 界面功能开发 / 体验优化，选填）。做法如下：

## 1. 准备

- 注册/登录 TRAE：官网 <https://www.trae.cn/>，下载桌面客户端（或手机版 TRAE App）。
- 本项目代码在手机环境 `/root/workspace/zhanggui-toolbox/`。建议先推送到 GitHub 仓库（见部署文档），TRAE 里直接克隆仓库最方便；或者把整个文件夹打包传到电脑后本地导入。

## 2. 在 TRAE 里建项目

1. TRAE 打开后 → 新建项目 → 选择本地文件夹（克隆/拷贝的 `zhanggui-toolbox`）。
2. 确保能跑起来：终端执行 `pnpm install && pnpm dev`。

## 3. 真实地用 TRAE 做几轮修改（重要）

问卷要求 SessionID 对应三个阶段，建议做三次真实会话，例如：

- **方案设计**：用对话模式问 TRAE「如何给这款小生意工具规划功能模块」，让它输出方案并保存为文档。
- **界面功能开发**：用 Agent 模式让它改一个真实功能，比如「把首页英雄区文案改成更口语化的版本」「给报价单增加一个 8% 税率快捷选项」，让它实际改代码并运行验证。
- **体验优化**：让它做一轮体验优化，比如「给移动端表格增加横向滚动提示」「统一按钮圆角」，改完自己跑一遍确认。

每轮会话结束，TRAE 会生成会话记录。

## 4. 找到 SessionID

- TRAE 客户端的会话历史列表里，每个会话可打开详情/分享；分享链接或会话详情中的 ID 即为 SessionID。
- 如果界面上直接显示 ID（形如一串字母数字），复制即可；如果只有分享链接，链接尾部的 token 就是 ID。
- 手机版 TRAE App 同样有会话记录入口。

## 5. 填写

把三个阶段的 SessionID 分别填到问卷第 20–21 题对应位置（无对应阶段的填你有记录的会话即可）。

## 说明

- 本题为「选填项后可填写」，但建议填写——它是大赛判断作品是否用 TRAE 开发的重要依据。
- 请只填你**真实在 TRAE 里做过的会话**，不要编造 ID；先在 TRAE 里完成上一步的修改，再填问卷。
